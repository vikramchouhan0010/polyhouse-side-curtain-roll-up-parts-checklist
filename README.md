# Polyhouse side curtain roll-up: parts checklist

A side curtain that rolls up and down is the main ventilation control in many Indian polyhouses. This checklist lists the parts to confirm before you order, from the questions BLUSTAL (a Ludhiana greenhouse equipment manufacturer, since 2004) gets from contractors and growers.

## Parts to count

- **Film or net for the curtain**: length of each side wall and curtain height
- **Roll-up pipe**: one run per curtain, sized to the span, with joints
- **Wiggle channel or clips and film fixing**: along the top and bottom edge of the curtain
- **Gear or handle roll-up unit**: manual or motorised, one per curtain run
- **Bottom weight or batten pipe**: keeps the film straight when rolled down
- **Clamps and connectors**: at each post or hoop

## Before you ask for a price

1. Measure each side wall separately: length and curtain height.
2. Decide manual or electric operation for each side. See the comparison in [manual vs electric greenhouse roll-up](https://www.blustal.com/manual-vs-electric-greenhouse-roll-up/).
3. Note wind exposure. A long curtain in an open field needs stronger fixing than one in a sheltered plot.
4. Ask the supplier to list every part with quantity, so quotations can be compared line by line.
